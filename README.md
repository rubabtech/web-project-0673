## Project Overview
Zohra Kitchen is a multi-page home bakery website. Visitors can explore cake designs, learn about the bakery and prepare a booking enquiry through WhatsApp.

## Technologies
- HTML5
- CSS3
- JavaScript

## Website Pages
1. Home
2. About Our Kitchen / Media and Info
3. Book Your Cake / Form
4. Cakes / Services
5. Gallery / Portfolio
6. Contact

## Assignment 1
The first part covers these three pages:

| Page | Files | Main Concepts |
| --- | --- | --- |
| Home | index.html, home.css | Headings, paragraphs, images, navigation and CSS selectors |
| About / Media | about.html, about.css | Audio, video, lists, table, box model, float and overflow |
| Booking / Form | booking.html, booking.css, booking.js | Form controls, validation, attribute selectors and pseudo-classes |

Each page uses its own stylesheet. Images are stored in the IMAGES folder, and audio/video files are stored in the MEDIA folder.

## Run the Website
Download or clone the repository and open index.html in a browser. Internet access is needed for Google Fonts, customer reviews and WhatsApp.
